## 🧠 思考の軌跡
1. **[P1] finish_run() の try/finally 保証**: `firestore_usecase.py` の `run()` メソッドで `start_run()` 後に例外が発生すると `finish_run()` が呼ばれない問題。try/finally ブロックで囲み、例外時は `status="failed"` で `finish_run()` を呼ぶよう修正。`raise` で例外を再送出するため呼び出し元の挙動は変わらない。

2. **[P1] GCP ワークフロー変数の不整合**: ワークフロー自体は `vars.*` と `secrets.*` を正しく使い分けていたが、README.md と AUTOMATION.md/JP が古い記述で全て「Secrets に登録」と案内していた。ドキュメント側を修正して Variables と Secrets を明確に区別。

3. **[P2] Firestore TTL の型修正**: `_ttl_after()` が ISO-8601 文字列を返していたが、Firestore TTL は timestamp 型フィールドのみ対応。`datetime` オブジェクトを返すよう1行修正。

4. **[P2] delivery 取得の 500 件上限問題**: `_dispatch_delivery_ids()` が `list_retryable_deliveries()` で最大500件取得してメモリ上でマッチしていた。新規 `get_delivery()` メソッドを追加し、delivery ID で直接取得する方式に変更。

5. **テスト追加**: `firestore_store.py` に24テスト、`firestore_usecase.py` に11テストを追加。71 → 106テストに拡大。

## ✨ 今日のハイライト！
