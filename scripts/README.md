# Commit scripts

## Rye から uv への移行

`commit.sh` は、現在の uv 移行差分を次の3コミットに分割します。

1. 依存関係メタデータ・lockfile・GitHub Actions
2. 開発・運用ドキュメント
3. コミットスクリプト自身と自動テスト

依存関係と GitHub Actions は相互依存するため、途中のコミットでもCIが成立するよう
同じコミットにまとめます。

各コミットには、件名と2段落の本文からなる複数行メッセージを設定します。

### 事前確認

既定では品質チェックとコミット計画の表示だけを行い、ステージもコミットもしません。

```bash
./scripts/commit.sh
```

### コミット作成

内容を確認した後、自分の権限で実行してください。

```bash
./scripts/commit.sh --apply
```

確認プロンプトを省略する場合:

```bash
./scripts/commit.sh --apply --yes
```

安全のため、次の場合は処理を中止します。

- 既にステージされた変更がある
- merge、rebase、cherry-pick などが進行中
- lockfile、lint、型チェック、テスト、workflow YAML の検証に失敗する
- 品質チェック中や確認待ちの間に uv 移行対象ファイルが変更される

uv 移行対象外の未ステージ変更は警告として表示し、コミットには含めずに残します。
処理途中で失敗した場合、作成済みコミットは巻き戻しません。原因を解消して再実行すると、
完了済みのグループをスキップして残りから続行します。

自動テストは fake `git` を使用するため、テスト実行によって実際のリポジトリへ
ステージやコミットが作成されることはありません。
